# penbridge-materials

PenBridgeの資料や保護者向け書類を、AIでデザインを統一して作成するための**スキル（Agent Skill）**です。

> **スキル（Skill）とは？**  
> AIに作業手順・文章ルール・デザインのひな形を覚えさせる設定パッケージです。ClaudeやChatGPTなどの対応AIに読み込ませることで、毎回細かい指示を書かなくても、誰が作っても同じ見た目の資料を出力できます。

## 作れるもの

原稿やメモを渡すと、ブラウザの印刷からそのままPDF化できるHTMLファイルを作成します。

- **スライド（A4横）**: 研修で映す資料、場面ごとに参照するマニュアル
- **文書（A4縦）**: 印刷して配る資料、上から順に読む手順書・説明資料
- **保護者向け定型書類**: 月次レポート、単元別評価表、学習ロードマップ、標準進行表

## 使い方

### 1. AIにスキルを渡す

- **URLでそのまま使う（手軽）**: Webを読めるAIに、このページのURLを添えて依頼します。
- **AIに登録して使う（毎回使う場合）**: 右上の **Code > Download ZIP** からZIPを落とし、ClaudeやChatGPTの設定（Skills）にアップロードします。

### 2. 原稿を渡して依頼する

原稿を貼るか添付して、作りたい形式と読み手を伝えます（A4縦にしたいときは「スライド」を「A4の文書」に変えます）。

```text
https://github.com/Monello-LLC/penbridge-materials のスキルに従って、この原稿をPenBridgeのスライドにして。読むのは新しく入った講師です。
```

### 3. 構成を確認してPDFにする

1. AIが先に構成案を見せるので、確認してからHTMLを作ってもらいます。
2. できたHTMLをChromeで開き、**印刷 >「PDFに保存」** を選ぶとPDFになります。

## ファイル構成

- `SKILL.md`: AIが読む作成手順と文章ルール
- `references/design.md`: 色、書体、余白、ロゴのルール
- `assets/template.html`: スライドと文書のひな形（ブラウザで開くと部品の見本が見られます）
- `assets/monthly-report.html` ほか: 保護者向け書類のひな形4種（月次レポート、単元別評価表、学習ロードマップ、標準進行表 ※見本の生徒は架空です）
- `assets/logo/`: ロゴマーク
