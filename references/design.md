# PenBridgeの資料の見た目

`assets/template.html` のCSSが正本である。このファイルには、CSSからは読み取れない決め方と理由を書く。

## 考え方

色とロゴはPenBridgeのものを使う。文字の大きさの段階、行間、字間は、デジタル庁デザインシステムのタイポグラフィにならう。飾りを足さず、文字と罫線と余白で組む。角は丸めない。

## 色

| 名前 | 値 | 使う場所 |
|---|---|---|
| `--navy` | `#001e43` | ロゴの文字 |
| `--blue` | `#014099` | 表紙の題、ページの題、章の扉の地、部品の見出し、番号、表の見出し行、言い方の例。サイトの学校ページの帯と同じ青 |
| `--yellow` | `#ffc810` | 表紙の短い線、章の扉の章番号。小さな面積にだけ使う |
| `--red` | `#d9121b` | 注意と、しないこと。ほかの用途には使わない。サイトのPICK UPの札と同じ赤 |
| `--ink` | `#1a1a1c` | 強めに読ませる本文 |
| `--body` | `#333333` | 本文 |
| `--muted` | `#626264` | 章の名前、ページ番号、小さな見出し |
| `--line` | `#d6d9e0` | 罫線 |
| `--mist` | `#f4f5fa` | 表の見出し列の薄い地 |

題と見出しはすべて青にする。ページ全体を青で塗るのは章の扉だけにする。紺はロゴだけに使う。箱の地は白にし、薄い罫線で囲む。箱や見出しに濃い色の線を足さない。黄は青の地か白の地に小さく置く。赤を飾りに使うと、注意の意味が伝わらなくなる。

## 文字

表紙の題も含めて、すべての文字をNoto Sans JPで組む。明朝のNoto Serif JPはロゴの文字だけに使う。

スライドでの大きさを示す。文書ではこの0.75倍になる。

| 用途 | 大きさ | 太さ | 行間 |
|---|---|---|---|
| 表紙の題 | 48px | 700 | 1.4 |
| 章の扉の題 | 45px | 700 | 1.4 |
| ページの題 | 36px | 700 | 1.4 |
| 要点の見出し、目次 | 24px | 700 | 1.5 |
| 題を補う文、言い方の例 | 22px | 400と700 | 1.5〜1.6 |
| 本文 | 20px | 400 | 1.6 |
| 表、チェックリスト | 18px | 400 | 1.6 |
| 章の名前、小さな見出し | 16px | 700 | 1.4 |
| ページの下のロゴと番号 | 14px | | 1.4 |

スライドでは14pxより小さい文字を使わない。文字を太くするのは見出しと言い方の例だけにし、本文の中の語を太字で強調しない。

見出しと短い文は、文節の切れ目で折り返す。語や学校名の途中で折れると読みにくいためである。

## スライドのページ

- 大きさはA4横の297mm×210mmである。
- 余白は上14mm、左右18mm、下20mmである。表紙と章の扉は左右28mmにする。
- 中身は題の下から上詰めで置く。ページごとに始まる高さを変えない。
- 表紙と章の扉を除く全ページの左下にロゴ、右下に資料の題とページ番号が出る。CSSが自動で付けるので、HTMLには書かない。

## 文書のページ

- 大きさはA4縦の210mm×297mmである。余白は上18mm、左右20mm、下22mmである。
- スライドと同じ部品を、0.75倍の大きさで使う。本文は15px、章の見出しは25.5px、節の見出しは19.5pxになる。文書用の部品を別に作らないのは、色や形を直したときにスライドと文書の両方へ同じように反映させるためである。
- 全ページの左下にロゴ、右下に資料の題とページ番号が出る。CSSが自動で付ける。
- 見出しの直後、部品の途中、表の行の途中ではページを区切らない。

## 保護者に渡す書類

`<article class="document for-guardians">` と書くと、題と見出しが紺になり、ページの余白が上14mm、左右16mm、下18mmに狭まる。スライドや社内の文書より多くの情報を1ページに入れるためである。

- 本文と表の文は12.75pxにする。社内の文書の15pxより小さくして、引き締める。
- 列の多い表は `for-guardians wide` と書いてA4横にする。
- 地の色を使うのは、科目、進み方、「あり・なし」の小さな札と、科目の配分の帯だけにする。表は横の細い罫線だけで区切り、枠で囲まない。枠の箱は線がちらついて読みにくかった。
- 区画の見出しは紺の文字にし、左に黄色の短い縦線を付ける。横の線は付けない。
- 表の見出しのすぐ下の線は濃いめ、行の間の線は薄くする。
- 広い面を色で塗らない。長い文を囲むときは薄い灰色の枠にする。
- 標準進行表の単元の帯だけは、科目の薄い色で塗る。今の時期は、時期の見出しを紺で塗って示す。黄色は社会の色と重なるので使わない。
- 題と生徒の情報の下に、細い区切り線を1本だけ引く。

## ロゴ

ロゴマークは `assets/logo/` にある。白い地には `penbridge-mark-color.svg`、青の地には `penbridge-mark-on-navy.svg` を使う。ひな形にはCSSの中に同じものが入っているので、スライドでは画像を貼る必要はない。

ロゴの形、色、縦横の比を変えない。ロゴの上に文字を重ねない。

## 写真と絵

原稿に付いていた写真や図だけを使う。AIで作った人物の写真や、飾りのためのイラストは入れない。
